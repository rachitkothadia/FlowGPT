# Security and privacy reports

Do not post API keys, passwords, browser cookies, account sessions, signing certificates, microphone recordings, or private transcripts in issues or pull requests.

For a sensitive report, contact the maintainer privately at **kothadiarachit@gmail.com**. Include affected app version, macOS version, reproduction steps, and the impact. Share only the minimum redacted evidence needed; no response-time guarantee is made.

FlowGPT's current bridge sends audio to OpenAI through the ChatGPT website. Local history is not encrypted by this app. A saved website session can expire, and Temporary Chat does not mean zero provider retention. See the [README privacy section](README.md#privacy).

Downloaded local builds are currently ad hoc signed and unnotarized. Verify the source and distribution status before use. A valid code signature alone does not establish Developer ID trust or Apple notarization.
